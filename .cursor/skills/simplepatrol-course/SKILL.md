# Курс SimplePatrol

Источник правды — `README.md` в корне репозитория. Фазы, подходы и статус там. Этот файл только говорит, как вести занятие.

## Когда автор просит продолжить

1. Прочитать `README.md` целиком. Текущая фаза — в «Где мы сейчас». «Следующий пункт» значит ближайшую неначатую фазу. Названный номер — эта фаза, если предыдущие уже пройдены.
2. Сразу переименовать чат через `rename_chat`. Заголовок взять из таблицы «Названия чатов», формат строго `P-№ - краткое название`.
3. Провести фазу по разделу «Как учиться»: теория, затем два-три подхода с плюсами и минусами. Практику и правки кода делать только после явной просьбы. Подход в код не выбирать за автора.
4. Когда фаза пройдена, дописать в «Где мы сейчас» одну строку: дата, номер, что разобрали, что решили применять.

Фазы не перескакивать и план в README не переписывать. Обычный вопрос по коду мимо курса в лекцию не превращать и чат из-за него не переименовывать.
