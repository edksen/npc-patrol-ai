# Курс SimplePatrol

Источник правды — `README.md` в корне репозитория. Фазы, подходы и статус там. Этот файл только говорит, как вести занятие.

## Когда автор просит продолжить

1. Прочитать `README.md` целиком. Текущая фаза — в «Где мы сейчас». «Следующий пункт» значит ближайшую фазу, у которой закрывающая практика ещё не в коде. Названный номер — эта фаза, если практики предыдущих уже закрыты.
2. Сразу переименовать чат через `rename_chat`. Заголовок взять из таблицы «Названия чатов», формат строго `P-№ - краткое название`.
3. Провести фазу по разделу «Как учиться»: теория, затем два-три подхода с плюсами и минусами. Подход в код не выбирать за автора, если фаза его ещё не зафиксировала.
4. Сразу сделать закрывающую практику этой фазы из `README.md`. Объём — только она. Фаза не пройдена, пока этот код не лежит в проекте и не делает названную проверку.
5. Когда практика закрыта, дописать в «Где мы сейчас» одну строку: дата, номер, что разобрали, какой подход, чем закрыли.

Фазы не перескакивать и план в README не переписывать. Обычный вопрос по коду мимо курса в лекцию не превращать и чат из-за него не переименовывать.
